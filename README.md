# CityLogistics — Frontend

Клиентская часть проекта CityLogistics: HTML/CSS и Vanilla JS, запросы к API через `fetch`.
Фронтенд общается **только с core** (`http://localhost:8080/api`). Бэкенд, схема проекта и
инструкция запуска описаны в README [citylogistics-core](../citylogistics-core).

## Страницы

- `index.html` — вход и регистрация.
- `html/profile.html` — кабинет клиента: создание заказа, история, статусы
  (`NEW → ACCEPTED → IN_TRANSIT → ARRIVED → DELIVERED`).
- `html/driver-dashboard.html` — кабинет водителя: назначенные заказы и кнопки смены статуса.

После входа фронтенд запрашивает `/api/auth/me` и по роли открывает нужный кабинет.
JWT хранится в `localStorage` и передаётся в заголовке `Authorization: Bearer <token>`.
Пункты меню, ненужные для роли, скрываются — но это только удобство: права проверяет
бэкенд (`403` при попытке вызвать чужой эндпоинт).

## Как запустить

1. Запустить бэкенд по README core (core на 8080, driver-service на 8082).
2. Запустить статический сервер **на порту 5500** (бэкенд разрешает CORS только для него):
   ```bash
   npx live-server --port=5500
   ```
   или расширение Live Server в VS Code.
3. Открыть `http://localhost:5500` (или `http://127.0.0.1:5500`).

## Известные ограничения

1. **Форма регистрации не работает.** Она отправляет только `email` и `password`, а API
   требует ещё `name`, `role` и для водителя `phone`, поэтому отвечает `400`.
   Пока что регистрируйтесь через API (пример `curl` в README core), а входите через сайт.
2. **Сообщения об ошибках.** Местами фронтенд читает `data.message`, а API возвращает
   ошибки в поле `error`, поэтому вместо текста ошибки может показываться общее сообщение.
3. **Часть полей формы заказа не сохраняется.** Цена всегда отправляется как 300, а
   телефон получателя, вес, тип груза и т. п. бэкенд не принимает и молча игнорирует.
4. **Адрес API зашит в код** (`js/script.js`, `js/driver-dashboard.js`).
5. **Возможен XSS.** Адреса заказов вставляются в страницу через `innerHTML` без
   экранирования. Вместе с токеном в `localStorage` это риск: вредный скрипт в адресе
   может прочитать токен.
6. `html/driver-form.html` — заглушка.
